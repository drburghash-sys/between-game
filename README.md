# بيننا | المضيف

لعبة زوجية ثنائية تعتمد على غرف خاصة ورسائل يديرها "المضيف".

## النسخة الأولى
- الزوج ينشئ الغرفة ويحدد البنود المسموحة.
- الزوجة تدخل بكود الغرفة فقط.
- واجهة محادثة مستقلة لكل طرف.
- الزوجة تستطيع تخطي أي سؤال بدون خصم.
- مزامنة فورية عبر Firebase Realtime Database.
- PWA قابلة للتثبيت على الجوال.

## التشغيل
افتح `index.html` عبر GitHub Pages أو أي استضافة ثابتة تدعم HTTPS.
